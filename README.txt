AM4 | اختبار الخوارزميات وC++
================================

الملفات:
- index.html : بنية الموقع
- style.css  : التصميم المتجاوب
- script.js  : الأسئلة، المؤقت، التصحيح، النتيجة والمراجعة

طريقة التشغيل:
1. فك ضغط الملف.
2. افتح index.html في المتصفح.
3. أدخل الاسم ثم ابدأ الاختبار.

الميزات:
- واجهة عربية RTL ومتجاوبة مع الهاتف والكمبيوتر.
- 25 سؤالاً، 4 درجات لكل سؤال، والمجموع 100.
- مؤقت 45 دقيقة، تنقّل بين الأسئلة وخريطة إجابات.
- تصحيح آلي ومراجعة الإجابة الصحيحة مع شرح.
- طباعة صفحة النتيجة.
- لا يتضمن الموقع أي اسم جامعة.

ملاحظة:
الخطوط تُحمّل من Google Fonts عند توفر الإنترنت، ويعمل الموقع دونها باستخدام خطوط بديلة.
